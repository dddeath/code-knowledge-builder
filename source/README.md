# Code Knowledge Builder

Code Knowledge Builder 把固定源码事实整理成两套互相对应的入口：人类通过简体中文页面理解项目，Agent 通过机器知识库精确定位源码、关系和项目记录。先选择下面的一项任务，就能直接得到可阅读、可核验的最终结果。

## 先选择你要完成的任务

| 任务 | 你会直接得到 |
| --- | --- |
| [了解本项目知识库结构](#了解本项目知识库结构) | 得到人类入口、机器入口和各自负责内容的说明。 |
| [让 Agent 安装本项目](#让-agent-安装本项目) | 得到可使用的项目、Skill、运行环境、最小可用性结果和卸载入口。 |
| [让 Agent 解释自己的项目](#让-agent-解释自己的项目) | 得到目标仓库的人类入口、问题结论、来源和待核验边界。 |

---

## 了解本项目知识库结构

### 你会直接得到

得到人类入口、机器入口、项目记录入口和 Agent 精确定位入口。

- `human/INDEX.md`：按任务选择阅读入口。
- `human/WIKI.md`：按页面职责理解知识库的组织方式。
- `human/RECORDS.md`：查找分析、修改、实验、问题和会话记录。
- `human/REFERENCES.md`：查找已经审阅的外部资料。
- `machine/knowledge.sqlite`：供 Agent 检索完整实体、关系、来源和项目记录。

### 复制给 Agent

```text
请说明这个 Code Knowledge Builder 输出中人类入口与机器入口分别负责什么，并告诉我从哪个页面开始阅读。
```

### 只验收最终结果

确认 Agent 返回了人类起始页、机器入口、每个入口负责的内容，以及与你当前问题相符的下一阅读位置；不需要检查 Agent 的内部执行过程。

## 让 Agent 安装本项目

### 你会直接得到

得到可使用的项目、Skill、运行环境、最小可用性结果和卸载入口。安装任务到此结束，不会同时改动业务仓库或建立业务知识库。

### 复制给 Agent

```text
请安装 Code Knowledge Builder 项目及其 code-knowledge-builder Skill。项目来源=<项目地址>，发布版本=<版本或分支>。请由 Agent 完成安装与最小可用性核对，只返回项目位置、是否可用、适用边界和卸载入口。本次只安装项目，不为业务仓库建立知识库。
```

### 只验收最终结果

确认 Agent 明确返回项目位置、Skill 是否可用、最小可用性结果、适用边界和卸载入口；安装成功提示本身不算最终结果。

## 让 Agent 解释自己的项目

### 你会直接得到

得到目标仓库的知识库位置、人类入口、问题结论、来源和待核验边界。结果同时说明支持结论的来源、适用边界和仍需核验的内容，安装与建库职责保持分离。

### 复制给 Agent

```text
请使用已经安装的 code-knowledge-builder 为 repository=<目标 Git 仓库> 建立或接管知识库，并回答 question=<项目问题>。请返回知识库位置、人类入口、问题结论、支持结论的来源、适用边界和仍需核验的内容。本次从已安装的 Skill 开始，不重复安装项目。
```

### 只验收最终结果

确认 Agent 返回了固定源码版本、知识库位置、人类入口、针对问题的结论与来源，并明确区分已确认事实和仍需核验的内容。

## 安装后继续指挥 Agent

你会直接得到一次指定阅读、定位、修改或核验任务的结果、来源和边界。

### 阅读已有知识库

让 Agent 回答问题时，直接说明问题和期望结果。Agent 会先读取与问题相关的紧凑知识，再在必要时定位少量源码；你会得到结论、关键来源、适用边界和下一步。

### 建立或接管知识库

知识库已经建立或接管后，再按目的指挥 Agent：

| 目的 | 你会直接得到 |
| --- | --- |
| 记录可复用结论 | 带来源回链的分析、修改、实验或踩坑记录。 |
| 维护现有知识库 | 当前一致性结果、需要修正的对象和最终状态。 |
| 迁移到新的源码版本 | 新旧版本边界、迁移结果、保留内容和恢复入口。 |
| 接入 Harness | 当前 Agent 工具中的知识库入口、能力边界和使用结果。 |

### 复制给 Agent

```text
请继续使用这个项目知识库完成 task=<阅读、定位、修改或核验任务>。先读取与任务相关的紧凑知识，再按需要窄读源码；返回任务结果、关键来源、适用边界和下一步。完整验证明细仅在我明确要求时读取。
```

### 只验收最终结果

确认 Agent 返回了本次任务的实际结果、关键来源、适用边界和可执行下一步。需要记录、维护、迁移或接入 Harness 时，再检查其最终交付位置与恢复入口。
