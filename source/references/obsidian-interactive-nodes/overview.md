# 全库功能层级白板

“生成知识库白板”读取当前 vault 绑定的完整知识库图，生成原生 `知识库总览.canvas`。不依赖 Provider、检索预算或手工导入格式。

## 职责导航与完整性

所有 `classification=page` 的既有页面进入功能目录。文件聚合页作为职责入口，声明页按最近的页面父级和文件聚合页组织层级。辅助实体首先遵循投影的 `owner_page_id`；无法映射的实体进入明确边界入口。每个实体恰好归属一个功能详情；主要页全部可搜索、分页和展开，分页只限制一次显示数量，不减少目录中的功能。

标题只截取已审阅 `meaning_zh` 的职责原句；缺少该句时保留符号及已审阅说明，未审阅内容明确待核验。所有功能的完整节点定义存于总览的 `ckbOverviewCatalog`。初始只显示六个职责入口，侧栏每页八项，点击时展开该功能与父链；已展开内容在再次生成时保留。辅助详情每次展开二十项。导航包含线不表示代码依赖或执行顺序。

## 稳定身份与跨版本更新

功能 key 为路径、语言、声明种类、限定名称和规范化签名的组合，不含行号、提交或机器实体 ID。具有稳定签名的重载独立定位；没有签名的同名声明按功能族聚合。路径、名称或签名真实改变不自动视为同一功能。

`ckbGenerated` 保存所属身份与上次生成字段。总览的 `ckbOverviewState` 保存已展开卡片/边和人工删除记录。字段级比较只更新未被人工修改的字段，布局和功能表单分别保留。临时退出主要页或当前图的对象标记 `ckbOverviewRetired`，仍保留身份与比较基线；重新进入不会撞上已解除所属的旧卡片。其他功能的展开不会复活人工删除的连线。

旧 0.9.0 的行号 key 通过卡片中保存的源码路径与限定名称进行唯一映射，迁移同时重写用户边端点而保留边本身；一个旧对象对应多个签名时明确要求迁移映射，不猜测。人工删除的节点不因自动生成复活，只有用户显式选择该入口才重新展开。

## 持久化、取消与来源

已有原生视图先保存，再以 `vault.process` 合并最新磁盘内容，并检测等待期间的原生编辑。所属/目标/输入冲突不覆盖用户文件。取消和卸载中止未完成读取，已保存的 Canvas 保留为原生文件。版本、建库范围和最近新鲜度记录分别展示；源码链接指向当前工作树，插件不重新核验或修改当前源码。

## 验证入口

插件 `scripts/build.py` 运行类型检查、lint、职责导航与稳定身份专项、原节点和 Provider 生命周期以及选区解释回归。专项包含同一顶级目录内六种职责、每个主要页可达、辅助所属、行号/实体 ID/排名变动、稳定签名、移出再进入、旧版迁移和一万个实体的完整功能目录。

`tests/fixtures/obsidian-interactive-nodes/overview-host.cjs` 在隔离 Obsidian 中验证检索与建库职责入口、按需展开、编辑、重开、跨版本身份、输入失败、取消卸载及包回滚。原 `host-smoke.cjs` 继续验证导入、编辑、用户边和原生保存保真。
