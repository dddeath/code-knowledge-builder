## 逐项边界

### 固定 Git 快照代码编译

- 状态：**已吸收**
- 领域：编译
- 输入：干净 Git commit 中受支持语言的 tracked 源码
- 输出：完整机器图、SQLite、保守中文人类页和来源链接
- 依赖：Git、Tree-sitter、对应语言服务器；版本由 toolchain.lock.json 锁定
- 许可证：CKB 原生实现；第三方运行时按锁文件和 THIRD_PARTY_NOTICES.md 聚合
- 数据边界：只把固定 commit 的项目源码作为来源事实；工作树修改进入独立覆盖层
- 完成门：分段审阅、来源、中文、关系、机器层和人类层全局审计全部通过
- 批次：既有能力

### 分段恢复与增量迁移

- 状态：**已吸收**
- 领域：编译
- 输入：大型代码仓库或上一版已审计知识库与新 Git commit
- 输出：可恢复 chunk、复用事实、delta 审阅包和当前版本完整输出
- 依赖：Python 标准库、Git 和现有解析/语义运行时
- 许可证：无新增依赖；沿用 CKB 与锁定运行时许可证
- 数据边界：仅复用 path、language、blob 和审阅字段形状完全匹配的事实
- 完成门：迁移审计与当前版本全部完成门同时通过
- 批次：既有能力

### 确定性 SQLite 查询

- 状态：**已吸收**
- 领域：查询
- 输入：自然语言问题、固定预算、页面上限和 fast/precise 档位
- 输出：可复查得分、来源范围和预算化 Agent pack
- 依赖：Python sqlite3/FTS5；不调用向量模型或网络模型
- 许可证：Python/SQLite 随现有运行时；无新增模型许可证
- 数据边界：只检索机器知识库、审核笔记、反馈和工作树覆盖层
- 完成门：重复查询排序一致、来源可打开、预算不超限且无隐藏模型调用
- 批次：既有能力

### 紧凑 Agent 阅读入口

- 状态：**已吸收**
- 领域：阅读入口
- 输入：问题、预算、页面上限和检索档位
- 输出：只返回 pack/record、开放反馈数、阅读入口和源码回退判断的紧凑 JSON
- 依赖：复用现有 retrieve，不新增依赖
- 许可证：CKB 原生实现
- 数据边界：完整候选、词项和得分保留在检索 record；首轮上下文不展开它们
- 完成门：与同参数 retrieve 绑定同一类事实，省略大字段且 Agent pack 可打开
- 批次：本批次

### 查询结论审阅后晋升

- 状态：**已吸收**
- 领域：查询
- 输入：简体中文分析正文与真实 query/pack

## 当前批次原则

- 本批次吸收有界机器操作日志：只保留固定机器字段和相对证据路径，不记录问题、对话或全文输出，也不新增人类知识页。
- 审阅文本资料层已进入默认本地路径；固定源码事实层仍不接收外部文档。
- 向量检索、PDF/网页/OCR 和自动页面扩散只在隔离 benchmark 中比较，不进入默认发行路径。
- 本地 Web 查看器、大型二进制复制和外部文档伪装成代码实体保持明确排除。
