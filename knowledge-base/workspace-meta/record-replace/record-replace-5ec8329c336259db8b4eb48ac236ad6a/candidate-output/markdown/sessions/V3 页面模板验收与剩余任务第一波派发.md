# V3 页面模板验收与剩余任务第一波派发

标签：#类型/会话

## 会话目标

完成人类层 V3 页面模板与渐进披露实现的独立验收，在通过后合并到集成分支、同步稳定知识库，并启动剩余待办事项的第一开发波次。

## 已确认决定

V3 模板按用户已经通过的标题与分节约束执行。导航页负责帮助人类找到任务入口；内容页使用书面标题并优先解释结果、适用条件和当前边界。完整测试命令、哈希、数据库检查和回滚探针继续保存在机器验证记录中。

## 当前进展

V3 实现已经完成独立复查并进入集成分支。稳定知识库已经更新到当前固定源码快照，原有工作记录、参考资料、研究缺口和两份学习笔记得到保留，旧知识库同时保留为回滚基线。

## 派发任务

第一波以三个独立 Codex 任务并行开发：

- C++ 局部语法错误改为有边界的警告，避免无关后续流程被阻塞；
- 建立 Git 驱动的源码事实新鲜度和临时工作树分层；
- 为 reference 层实现原生 PDF 优先、页级可追溯并可选 OCR 的吸收流程。

中文检索效果复测、tag 导航调研和既有页面的 V3 迁移继续留在队列，等待本波释放并行槽位。Canvas 实验功能等待用户试用反馈。

## 后续条件

每个开发任务必须返回独立提交、真实运行测试、失败样例和可执行回滚。管理任务独立复查全部门后才合并；源码合并后再以隔离 staging 更新稳定知识库。所有开发分支完成后统一复核 GitHub 发布。
