## 48小时应急：合计8小时

规划假设：两天各4小时，可按面试时间拆分；目标是产出可检查的口述、图和代码，不保证一次掌握全部。

| 时块 | 阅读或练习 | 必须产出 |
|---|---|---|
| 第一天45分钟 | 速查1-7、C01/C17 | 录制联合90秒、实习60秒；列真实案例缺口 |
| 第一天60分钟 | C02-C08 | 画固定版本到检索图；复算Flask数据；写出符号下钻边界 |
| 第一天75分钟 | C09-C16 | 画Parent/Surface状态图；工具未返回/E5超时各一个反例 |
| 第一天60分钟 | C18、EX01 | 写配对切分与pending测试；解释RAII和虚拟地址 |
| 第二天60分钟 | A01-A08或B01-B08 | A写奖励领取判据；B写代码助手接口和失败状态 |
| 第二天60分钟 | A选EX05/06；B选EX02/04 | 运行两个正常与两个边界测试；记录第一次错误 |
| 第二天60分钟 | 模拟面试45分钟+评分15分钟 | 完整记录、分项评分和一项最高风险薄弱点 |
| 第二天60分钟 | 重做错误题、脱稿回讲 | 同一题用不同输入解释；更新掌握等级 |
