# layout_text 等测试场景

标签：#类型/代码

> 该脚本使用 Poppler 渲染指定单页 PDF，再调用 RapidOCR 获取文字框，按几何位置重建行列间距和代码缩进，并输出文字、平均置信分值、识别引擎及渲染证据。 它是可选真实 OCR 基准适配器而非默认依赖，支持渲染前后取消检查；整体超时由父提取流程管理，几何布局重建是启发式推断而不是原始排版精确还原。

## 什么时候需要修改

OCR 引擎、单页渲染参数、文字框布局、置信度聚合或适配器输出合同变化时修改此脚本，并用代码和表格保真指标分别评估。

## 内部细节

<details><summary>查看本页收纳的 6 个辅助实现</summary>

| 代码单元 | 一句话作用 |
|---|---|
| `_tool` | 按环境变量或命令搜索路径定位 OCR 所需工具，显式配置失效时直接报错。 |
| `_bounds` | 将 OCR 多边形检测转换为矩形边界、去空白文本及数值置信度。 |
| `_group_rows` | 根据检测文本框的纵向中心和高度分组为行，再按横坐标排列同一行的文本。 |
| `_character_width` | 从包含足够 ASCII 字符的检测框估计字符宽度，没有可用样本时使用固定回退值。 |
| `run` | 渲染指定 PDF 页并调用 RapidOCR，按布局整理文本并写入引擎信息；取消文件只在渲染前后检查，不承诺推理中即时中止。 |
| `main` | 解析 OCR 单页提取参数，调用适配器并把异常写入错误输出，以非零状态结束。 |

</details>
