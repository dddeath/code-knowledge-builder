## 修改内容

integration branch 已普通合并低版本完整知识库批量迁移，保留开发分支的十个独立 commit和两次管理 merge。新增 `migrate batch plan/apply/resume/status/audit/cutover/rollback`，使用显式 manifest、真实版本矩阵、逐库 staging、兼容迁移、delta review、cold build、owner-token、独立备份、部分失败续跑、逐库 cutover 和全层 rollback。

## 修改原因

原协议批量接口只迁移 Agent Policy，无法批量升级 state、facts、graph、review、人类投影、双 SQLite、reference、gap、operation journal 和学习笔记。管理首轮审计发现 origin record 越界读取和相同 recovery root 无法 rollback；合并后回归又发现测试硬编码 worktree 父层级。三个缺口均在原分支新增独立 commit 后关闭，未通过整树覆盖或 squash规避。

## 验证结果

管理探针确认畸形 `origin.records` 与 backup/quarantine 冲突均在 state、staging、backup 和 control 写入前拒绝。合并后从真实 integration 根完成十四项完整迁移专项、双历史版本 E2E、五项 scope extension、十八项 Agent Protocol batch、三十七项 CKB core、二十二项 automation、一项 incremental migration 和三项 package release，全部 exit 0。

真实历史 E2E 从两个仓库历史 commit 构建旧 OUTPUT，再执行当前 plan、apply、audit、cutover 和 rollback；旧/新检索通过且旧树字节恢复。正式保留 fixture 验证迁移前后工作记录、一个 reference、三个 open research gap 和两份学习笔记原文不丢失。完整 post-merge 证据位于 `E:\knowledge_builder\artifacts\verification\knowledge-base-batch-migration\post-merge-verification.json`。当前只完成源码合并；最终稳定知识库仍需在隔离 staging 迁移、审计和切换后才能报告同步完成。
