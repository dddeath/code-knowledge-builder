# 调整 C++ 局部语法诊断的阻塞边界

标签：#类型/变更

## 修改内容

C++ 源码中的局部语法诊断不再自动中断后续建库。只要错误能够归因到有限声明范围，系统会保留已确认的其他源码事实，并在检索结果中提示该范围的结论不完整。

## 修改时间

2026 年 9 月 3 日。

## 修改原因

预处理条件附近的声明、`const T &x(expr)`、显式模板实例化等合法或有歧义的 C++ 形式，可能产生局部解析诊断。此前这些诊断会阻断整批流程，使 Agent 无法继续使用已经可靠提取的事实。SCons 工程又经常没有 `compile_commands.json`，需要明确区分精确语义与有边界的近似语义。

## 修改方式

解析阶段现在识别诊断影响范围，并为受影响实体附加稳定警告标识；检索包继续返回未受影响事实，同时禁止根据缺失结果推断源码中不存在对应实现。没有编译数据库时，系统只从唯一、可核对的 SCons 编译标准生成近似参数。跨提交复用解析结果时，警告及其实体引用会同步重键到新提交。

## 关联影响

这项修改同时影响 C++ 实体提取、语言服务器诊断、SCons 编译信息回退、增量迁移和 Agent 检索结论边界。依赖缺失、源码根不可用或无法局部归因的广泛语法错误仍会停止对应构建阶段。

## 已验证结果

固定样例已覆盖预处理条件、引用直接初始化、显式模板实例化、局部错误警告、广泛语法错误、SCons 无编译数据库以及跨提交警告重键。真实 clangd 集成验证确认：有明确编译数据库时保持精确语义，没有编译数据库时继续执行并明确标记为有边界近似。
