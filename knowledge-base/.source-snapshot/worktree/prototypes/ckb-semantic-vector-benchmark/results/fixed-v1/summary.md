# 固定语义向量检索对照结果

## 结论

本轮不建议把该语义向量路线或 RRF hybrid 进入生产实验。真实 `semantic-vector` 相对 `sqlite-current` 的 Recall@8、MRR@8、nDCG@8 分别下降 0.166666667、0.316666667、0.281893653。`hybrid-rrf` 把 Recall@8 从 0.750000000 提高到 0.833333333，但 MRR@8 与 nDCG@8 分别下降 0.022817460 和 0.000892723，不满足“至少一项提升且其余不回退”的冻结门。

正式报告状态为 `failed`，唯一失败门是共享的额外子进程上限：`sqlite-current` 与 `hybrid-rrf` 在新鲜度核对期间峰值出现 3 个 `git.exe`/`conhost.exe` 子进程，超过冻结上限 1；真实向量臂为 0。阈值未在观察结果后调整。
