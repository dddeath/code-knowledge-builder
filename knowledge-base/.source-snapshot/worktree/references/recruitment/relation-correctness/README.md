# Python 词法关系消歧

列表 `failed.append()` 不再连到测试中同名的局部函数。真实局部函数、闭包、同文件声明、显式模块/别名/相对导入及普通方法接收者仍产生可定位的候选关系。

## 解析规则

Tree-sitter 继续生成实体、稳定标识和源码范围。Python 标准库 AST 仅补充词法绑定：先记录声明、导入、参数和写入，再按使用位置所在作用域查找绑定。函数体不继承类命名空间；嵌套函数的使用不重复归到外层函数。字符串和注释不参与标识符关系匹配。

成员访问先解析接收者。列表和未知对象的成员没有可证明的项目实体目标，保持未决，不生成猜测目标的内部边。重复绑定、参数遮蔽、赋值、异常捕获、模式绑定及推导式绑定采取保守消歧。普通实例方法的首参数和 `classmethod` 可定位本类声明；静态方法和任意装饰器不据首参数推断接收者。

显式属性赋值、增量赋值和删除按“接收者绑定＋成员名”在当前词法作用域及其子作用域内保守失效。模块导入别名共享同一模块接收者；`self`／`cls` 使用已知类绑定。其他成员、其他接收者和兄弟函数的候选不因该局部写入被清空。此规则不模拟执行顺序；同一作用域内写入前的同成员引用也可能保守退为未决，跨函数运行时副作用仍不作确定性推断。

关系仍使用 `tree-sitter-lexical-candidate`，证据增加表达式、行列及 `python-lexical-binding`。这些是词法候选，不是运行时派发证明。`contains` 关系和非 Python 解析路径保持原规则，C++ 局部诊断阈值没有变化。

## 验证与回滚

使用包含项目锁定 Tree-sitter 包的 Python 执行 `tests/test_recruitment_relation_scope.py`；`--measure` 输出逐项标签、实际目标与汇总。`verify_replay.py --out OUTPUT` 在临时目录读取固定基线、运行相同测试、应用当前分支补丁，再执行输出目录的 `rollback.py`，重跑并核对基线结果及原文件哈希。验证目录保留完整命令、字面输出、退出码、补丁和回滚脚本；临时源码自动清理，不复制运行时。

## 适用边界

- 未决项沿用现有关系接口：保留源码但没有内部目标边，本次没有新增未决项数据库或页面接口。
- 导入按仓库相对模块路径精确匹配，不猜测任意目录后缀；运行时 `sys.path` 修改、额外 source root、动态导入、星号导入和对象类型推断仍待语义 Provider 解决。
- 赋值、多重绑定和全局/非局部写入采取保守失效，可能漏掉可由控制流证明的依赖。继承覆盖、动态成员替换和运行时猴子补丁不由本词法候选证明。
- Python AST 不接受的语法不退回全仓正则猜测。Python 宿主版本对可解析语法的影响需在生产 Windows 环境复核。
- 未重建稳定知识库；历史检索视图仍是旧事实，其 freshness 未确认当前。人类投影如何表述候选由独立任务验收。
