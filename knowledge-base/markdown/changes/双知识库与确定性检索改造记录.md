# 双知识库与确定性检索改造记录

标签：#类型/变更

## 修改内容

自身知识库已经从单一页面索引升级为事实层、完整机器 SQLite 和保守中文人类 vault。新增分节全文索引、确定性 fast/precise 图检索、实体与邻居查询、源码范围读取、Agent 会话排队与结束记录，以及机器/人类独立完成标记。

## 修改原因

项目规模增长后，单一 Markdown 页面集合无法同时满足 Agent 的完整召回和人类的低认知负担。三层设计让 Agent 查询全部实体和源码证据，同时把人类页数、属性和关系保持在保守配额内。

## 验证结果

自身扫描覆盖二十六个源码文件、三百三十八个实体和一千三百二十条关系，形成五十七个人类导航页与二百八十四个附属实体。二十七个逐实体审阅包、二十一项全局门、简体中文覆盖、SQLite 完整性、确定性重复检索、可点击源码与三个完成标记全部通过。
