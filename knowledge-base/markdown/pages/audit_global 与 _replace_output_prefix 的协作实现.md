# audit_global 与 _replace_output_prefix 的协作实现

标签：#类型/代码

> 该模块把固定 Git 快照转换为经过语法、语义、来源和中文审阅核验的知识库，生成完整实体事实、受预算约束的人类导航、Markdown 镜像与机器索引，并可额外生成 Logseq 数据库。完成状态必须经过批次、审阅包和总审计门。 它编排初始化、解析批次、审阅回填、图合并、多层投影和收尾状态，固定页面配置与源码范围，并在迁移后修复受管路径。总审计还会重建投影和索引，因此属于有写入副作用的完成流程而非只读状态检查。

## 什么时候需要修改

构建阶段顺序、审阅与完成门、固定快照迁移、页面导航及预算规则、多种投影一致性或上下文生成方式变化时修改此模块，并验证未审阅状态、源码漂移、镜像一致性及实际完成标记。
