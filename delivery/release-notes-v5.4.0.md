## 这版可以直接做什么

- **把 README 中的提示词交给 Agent**：安装 Skill、了解本项目，或为当前代码仓库建库，不必先学习命令行参数。
- **一键生成知识库白板**：安装独立 Obsidian 插件后，点击“生成知识库白板”，从功能总览逐层展开；辅助实体收纳在详情中。
- **保留自己的白板编辑**：再次生成时保留人类新增卡片、文字、布局和连线；源码行号或提交变化不会单独造成重复功能卡片。
- **阅读与源码对应的项目知识库**：发布仓库同时包含源码、中文阅读入口和可检索知识，历史笔记及参考资料继续保留。

## 选择安装包

| 安装包 | 适合谁 |
| --- | --- |
| `code-knowledge-builder-lite-5.4.0.zip` | 使用核心 Skill 建库、检索和维护。包含完整核心功能，运行环境由 Agent 按操作系统准备。 |
| `code-knowledge-builder-full-win-x64-5.4.0.zip` | Windows x64 用户希望同时获得核心 Skill 与锁定的离线运行环境。与 Lite 二选一即可。 |
| `code-knowledge-builder-obsidian-0.9.1.zip` | 已有 CKB 知识库，希望在 Obsidian 中使用功能白板。它不是核心 Skill 安装包。 |

核心 Skill 与 Obsidian 插件独立安装。不使用 Obsidian，也可以正常建库和提问。白板生成与编辑不需要模型配置；白板中的讨论功能需要可用模型服务。

## 使用范围

Canvas 仍是实验功能，欢迎反馈实际使用体验。它展示知识库绑定的固定源码版本，不会自动修改源码或替代知识库同步。源码改名、签名变化及旧白板中的歧义映射，不会被自动认定为同一功能。

本版验证覆盖白板生成、功能导航、重复生成、保存重开、人类编辑保留、插件升级设置保留，以及知识记录修订和迁移恢复。这里不宣称所有模型服务或所有仓库都已重新测试。

从发布仓库的 `README.md` 开始；直接阅读知识库时打开 `knowledge-base/human/INDEX.md`。下载源码与知识库使用 Git LFS，若文件仍是指针文本，请让 Agent 完成 LFS 文件下载。异机继续维护时，由 Agent 先确认源码与运行环境绑定。
